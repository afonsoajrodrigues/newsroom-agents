# Verification standard

## Confidence scale (use these words, nothing else)
- **CONFIRMED**: an official record, or two independent primary sources that agree.
- **LIKELY**: one credible primary source, or several secondary sources that trace to different originals.
- **UNVERIFIED**: a claim with no corroboration found. Not "false"; not "true".
- **DISPUTED**: credible sources conflict and no tie-breaker was found.
- **FALSE**: contradicted by an official record or primary evidence.
Never round UNVERIFIED toward TRUE or FALSE on plausibility.

## Independence test
Two sources are independent only if neither derives from the other and they do not share an original. Ask: where did each get it? Wire copy, a press release, a single leaked memo, or one anonymous official reproduced by five outlets is one source. Trace lineage before counting.

## Primary-source rule
Find the thing itself: the gazette entry, the contract page, the ruling, the dataset, the recording. A report about a document is not the document. If only secondary sources exist, say so in the rating line.

## Currency
Statistics get revised; laws get amended; pages change. Record the version or date you used. Check the primary publisher for a later revision before citing a number.

## Citation format
`Claim -> Rating -> Evidence (URL or document, access date) -> One-line justification`.
Web sources must be archived (Wayback or archive.ph) before a rating of CONFIRMED; note the archive link.

## Quotes
Locate the primary audio, video or transcript. Rate accuracy and context separately: an accurate quote used to imply something the speaker did not mean is flagged as MISLEADING CONTEXT, not as false.

## Language
Portuguese names: search surname-first and surname-last, with and without middle names and accents. Institutional names: search the official acronym and the full name (IMPIC, Instituto dos Mercados Públicos...).
