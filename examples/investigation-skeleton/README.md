# Investigation folder, as `/newsroom-core:start-investigation` creates it

What a case folder looks like after the scaffold and a first pass by `procurement-watchdog` and `web-archiver`. The rows are real (they come from the Lisbon example) and show the conventions: one fact per row, access date, archive link with hash, confidence on the desk's scale, a public-interest note where a private person would appear. `investigations/` is gitignored in real use; this copy lives under `examples/` only to show the shape.
